# Lucas Digital — Portfólio

Site de portfólio profissional de fotografia, vídeo e tráfego pago (Meta Ads), de Araranguá, Santa Catarina.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — estilos (dark mode, layout, responsividade)
- `script.js` — menu mobile, filtro de portfólio, modal e formulário

## Tecnologias

- HTML5
- CSS3
- JavaScript puro (sem frameworks)

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador — não precisa de instalação nem servidor.

## Publicar com GitHub Pages

1. Faça o upload deste arquivo `index.html` (e este `README.md`) para o repositório.
2. No repositório, vá em **Settings → Pages**.
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
4. Salve — em alguns minutos o site estará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO`.
